# FitFinder

FitFinder is a university project that helps people find fitness coaches suited to their goals and location.

**Live website:** [https://soraskiee.github.io/FitFinder/](https://soraskiee.github.io/FitFinder/)

## Features

- Browse coach profiles with specialties, experience, ratings, hourly fees, and locations.
- Filter coaches by location and specialization.
- View coach profiles and request a free consultation.
- Explore fitness transformation stories.
- Calculate BMI.
- Share website feedback or review a coach.
- Open sign-in, registration, and coach application forms.

## Run locally

Clone the repository and open `index.html` in a web browser. FitFinder uses plain HTML, CSS, and JavaScript, so no package installation or build step is needed.

## Project files

- `index.html` — page structure and forms
- `style.css` — visual styles and responsive layouts
- `script.js` — coach listings, filters, and interactive behavior
- `images/` — logo, coach photos, and transformation images

## Built with

HTML, CSS, and JavaScript.
